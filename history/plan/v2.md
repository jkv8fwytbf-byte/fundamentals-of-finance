Dated 2026-09-14. Replaces v1 after Siddharth's review. Three research passes (corpus, tool
landscape, and a second round on pi, Artificial Analysis, the managed stack, critics, learning

## Context

Siddharth wants a long-horizon (no intraday/day-trading) system that automates Aswath Damodaran's
valuation approach across many companies and sectors so a diversified watchlist can be valued from
fundamentals, an "Ask Damodaran" chat grounded in the corpus, and a platform that scales. He wants
to learn the tooling as he builds, wants everything on managed services, and wants an honest way
to find out how wrong the method is. The public Damodaran corpus is already collected in
`~/Downloads`. The spreadsheet model is fully reverse-engineered and ships its own golden case.

## Verified facts that shape the design

- **The model.** `~/Downloads/fcffsimpleginzu.xlsx` (17 sheets, including the literal sheet names
  `Input Stat Distributioons` and `Trailing 12 month Worskheet`, which any loader must match
  exactly). The shipped Almarai case caches value/share `7.1878402700621136`, price 72.28, cost of
  capital 0.070550157406465405, terminal WACC 0.0881 (formula: rf + mature ERP, although the label
  says "+4.5%"), reinvestment lag 1. The shipped case uses the Actual-rating path (A1/A+); the
  synthetic path gives 0.058651 and is a separate unit test. Excel and JavaScript both compute in
  IEEE-754 float64; node reproduces the cached value with |Δ| = 0, so a TypeScript port can hit
  1e-6 without decimal libraries.
- **Datasets.** 29 families × 8 regions, 94 industries everywhere; the workbook's Global table is
  byte-identical to the Jan-2026 files. One 2026 snapshot carries three risk-free rates (3.95 /
  4.58 / 4.75%) and three ERPs (4.20 / 4.23 / 4.46%) because ERP is monthly, CRP quarterly, industry
  annual. India Jan-2026: Baa3, default spread 1.87%, ERP 7.08%, CRP 2.85%. 27 of 94 India rows
  (and 9 of 94 US rows) have fewer than 10 firms. 248 of 275 current files are `.xls` (BIFF8).
- **Corpus.** ~30 M tokens after dedup (~60k chunks). 609 blog posts with clean front matter
  (years 2012 and 2025 missing; that is where the Facebook IPO and DeepSeek/Nvidia posts live).
  pptx packets carry 568 speaker-note blocks. The 2023 book markdown has 13,515 broken fi/fl
  ligatures. All 1,477 transcripts are unpunctuated auto-captions. Exam + solution pairs form a free
  eval set. The Pinecone upload from the other session never ran (its log: no API key, 0 files).
- **Data sources.** SEC EDGAR companyfacts is free and public domain (LTM = last 10-K − prior-year

- **Machine.** macOS arm64, node 26, git, `gh` authenticated as `jkv8fwytbf-byte`, `~/.pi` absent,

**Stateless, scales for free:** every Next.js route handler and server component (Vercel
autoscales to 30,000 concurrent on Hobby); the engine (pure: no network, env, clock, DB);
Pinecone queries (read units, not instances); Actions jobs (matrix up to 256 parallel).

**Not horizontally scalable, and the fix:** Neon's single write endpoint (batch `COPY`, never one
INSERT per fact; `neon-http` on the pooled URL because Vercel shares 1,024 file descriptors).
Source rate limits (SEC ~10 req/s: refresh only on new filings by polling `submissions` for a new
accession number, never nightly full pulls; EODHD fundamentals cost 10 call-units each, so weekly,
keyed on `UpdatedAt`). Vercel's 4.5 MB body cap (page the industry table). GitHub Actions gotchas,
recorded in `docs/decisions/002-scheduler.md`: jobs cap at 6 hours (chunk the transcript job into
runs of ~300 files) and scheduled workflows on public repos are auto-disabled after 60 days without
commits (a monthly `keepalive.yml`).

**Your UI worry, answered.** The picker → tabs → chat sketch is fine as a **thin client**. The
picker reads a precomputed `valuation_run` row (milliseconds). "Recompute" is a server action
calling the pure engine synchronously (milliseconds) and writing a new run row. The chat tab
touches Pinecone + OpenRouter and never the engine. RAG cost is O(1) in corpus size: 8 chunks per
question whether the corpus is 30 M or 300 M tokens. Going from 50 to 5,000 names changes the
Actions job shape and the Neon tier, not one line of UI. The three things that would force a
rewrite (per-user mutable portfolios, real-time prices, per-request LLM cost growing with users)
are all out of scope by your own decision.

## Is RAG worth it, and which models (from Artificial Analysis, priced on OpenRouter)

**RAG is required, not optional.** The corpus is 30 M tokens; the largest context window on
OpenRouter is 2 M (Grok 4.20), so a single full-corpus call is arithmetically impossible. Cost per
question: 8-chunk RAG on GLM-5.3-Flash = **$0.00155**; stuffing one 200k-token packet = $0.0304
(19.6× more); stuffing the whole corpus in 15 calls = $4.50 on Flash or $300 on a frontier model.
The index build is $0 (Voyage's 200 M free tokens cover 30 M). Only RAG returns chunk ids that
become citations with licence and vintage. Use long context only for single-document questions
("summarise the 2026 packet"): a hybrid router picks the path.

|---|---|---|---|
| pi daily driver (~75% of turns) | `z-ai/glm-5.3-flash` | 0.15 / 0.50 (0.03) | AA II v4.3 = 42, third-best open weight, 9.3× cheaper than GLM-5.3 |

## Engine design (TypeScript)

`valueCompany(inputs: ValuationInputs): ValuationOutput`, pure. Output: `valuePerShare`, `price`,
`priceAsPctOfValue`, the 10-year table, terminal block, bridge, `impliedVariables`, `inputsSha256`,
`audit` (`terminalCostOfCapital`, `ratingBasis`, `interestMissing`, `industryTierUsed`,
`vintage{market,crp,industry}`, `sources[]`, `engineVersion`). Modules ↔ sheets: `rating.ts` ←
Synthetic rating; `costOfCapital.ts` ← Cost of capital worksheet + Answer keys; `fcff.ts` /
`terminal.ts` ← Valuation output rows 2–21; `failure.ts` ← Failure Rate worksheet; `options.ts` ←
Option value (disabled for Almarai; fixed-point loop raises on non-convergence when enabled);
converters ← R&D/lease sheets (deferred); `india.ts`; `reverseDcf.ts`; `monteCarlo.ts`. The
industry-average and distribution approaches add `(rf − table.embedded_rf)` where `embedded_rf` is
stored per table (4.58% for the workbook tables, 3.95% for `wacc.xls`), never a literal. Diagnostics
become code: hard errors (terminal WACC ≤ g, no industry row after the fallback walk, missing
interest expense with synthetic rating chosen, currency mismatch, vintage mixing under strict
policy) and warnings (the sheet's six checks with fix-it text; g > rf + 0.5pp; the terminal-year
CRP drop printed in percentage points; effective tax outside [0, marginal]; negative reinvestment;
CRP vintage > 6 months; industry table > 12 months; rf older than 31 days; fallback used).

## Vocabulary you asked about (plain English, current as of Sept 2026)

- **Harness.** The scaffolding around a model: what goes into the prompt, which tools it can call,
  the loop of "call model → run tool → feed result back", permissions, and the UI. The model is the
  engine; the harness is the car. "Fine-tuning the harness" means shaping that scaffolding
  (AGENTS.md, skills, extensions, tools, output schemas, evals). Costs only your time.
- **pi (pi.dev).** A minimal, MIT harness by Mario Zechner (repo now `earendil-works/pi`, 105k
  stars). Four built-in tools (read, write, edit, bash), a system prompt of ~1.4k tokens (vs ~31k
  for Claude Code), extensions in TypeScript, skills (on-demand instruction packages), prompt
  templates, a branching session tree (`/fork`, `/tree`), OpenRouter built in (`/login openrouter`
  or the env var), live cost in the footer, and headless modes for CI. It deliberately omits
  permission popups, sandboxing, MCP and sub-agents; the plan adds the repo's own `sandbox/`,
  `permission-gate.ts` and `protected-paths.ts` extensions, `pi-mcp-adapter` for MCP, and
  `pi-subagents` only if needed. Day one "feels sparse until the extensions are in", so M1 installs
  them before the first real task.
- **OpenCode vs Claude Code vs pi.** OpenCode (MIT, 75+ providers) and Claude Code
  (Anthropic-only, built-in permissions) are the alternatives; you chose pi. Measured: pi 21/30
  tasks at $1.64 vs OpenCode 19/30 at $2.25 on one benchmark, slower wall-clock.
- **OpenRouter.** One API key and one bill in front of ~445 models. No markup on tokens; 5.5% fee on
  credit purchases. Swap models by changing a string; `data_collection: 'deny'` keeps prompts out
  of training sets. It has no embedding models, hence Voyage.
- **Open-weight model.** A model whose weights are downloadable (GLM, Kimi, Qwen, DeepSeek). You
  do not run it yourself; OpenRouter routes to hosts. Fine-tuning one changes form, not facts; not needed.
- **Artificial Analysis.** Independent benchmarks. Intelligence Index v4.3 (10 evals), Coding Agent
  Index v1.5 (for the harness), AA-Omniscience (hallucination; the metric that matters for a
  citation-bearing chat), and the Search Index from your screenshot (web-search APIs). Pick by the
  sub-benchmark that matches the job, not the headline.
- **RAG.** Split documents into chunks, embed them, retrieve the few most relevant for a question,
  answer from those with citations. Required here because the corpus is 15× the largest context window.
- **Pinecone / Voyage.** Pinecone stores and searches vectors (free Starter tier holds this corpus
  several times over). Voyage turns text into vectors and reranks results (200 M free tokens).
- **Vercel / Neon / Blob / GitHub Actions.** Vercel builds and hosts the app from every push (preview
  URL per PR; Hobby is free but non-commercial and cron is once a day). Neon is managed Postgres with
  a branch per PR. Blob is Vercel's file store for raw bytes. GitHub Actions runs tests on every PR
  and doubles as the job scheduler.
- **Git branch / PR, worktree, secrets, sandbox, MCP, Linear, Figma.** A branch is a parallel draft;
  a PR asks to merge it with a diff and CI checks. A worktree is a second checkout (optional).
  Secrets live in `.env` (gitignored) and provider secret stores, never in code or chat. A sandbox
  is the fence around what an agent can touch; pi's comes from an extension. MCP is the standard
  plug for tools ("USB-C for AI"); pi speaks it through an adapter. Linear and Figma are optional
  side-lessons (GitHub Issues and shadcn/ui components cover this app).
- **Scalability here** means: adding a company, sector, region or vendor is a data change; every
  number carries source, licence, fetch time and vintage; compute that grows with the universe runs
  as managed jobs; the UI is a thin client over stateless APIs.
- **Shorting.** Borrowing shares to sell now and buy back later; unlimited theoretical loss; in
  India via futures/options. Out of scope. The platform can flag "price far above value" names.

## Non-goals, risks, cut lines, deferred

**Non-goals for v1:** holdings/P&L, real-time prices, multi-user, commercial use, any buy/sell
output, scraping screener.in/Tickertape/Bloomberg, Docker or self-hosting, Python in the production
path, the option-value and lease/R&D converter sheets, fine-tuning any model.

**Risks → mitigations.** Operation-order drift breaks 1e-6 → per-module sub-assertions, a 1e-9
warning, a second golden case later. pi "feels broken" on day one → guard-rail extensions in M1
before the first task. Extension guards are advisory → the OS sandbox `denyWrite tests/golden/**` +
the required CI check are the real boundary. Neon Free 0.5 GB → `indname.xls` and fact history push
it; plan Launch (~$5–15) at M8. Pinecone write units on re-embeds → content-hash manifest. Actions
6-hour cap and 60-day auto-disable → chunked jobs + keepalive. Licence leakage → NOT NULL + DB CHECK
+ retrieval allow-list + `data_collection: deny`. Corpus gaps (2012, 2025; the three Dark Side decks
are image PDFs needing OCR) → backfill before tier 1 is declared complete. Harness dependence →
attempt-then-ask, own the tests, one no-harness evening a week, a decisions log. GLM-5.3 licence is
bespoke → fine for personal research; re-read before commercial use.

**Cut lines:** per milestone above. Globally: if month 3 arrives with M8 unfinished, ship US-only
with the pi extension and postpone EODHD rather than ship India without the fallback tests. Never
cut: the golden test in CI, three NOT NULL vintage ids, source + licence NOT NULL, India fallback
logging, the no-advice test.

**Deferred:** QStash/Inngest fan-out (beyond ~500 names); Vercel Workflows; sparse hybrid index
(measure first); NSE bhavcopy loader; the four remaining regional tables and `indname.xls`;
option value and converters; second golden case (Apple TTM); `pi-review.yml`; pi sub-agents;
Exa/GDELT news discovery; backfill of blog 2012/2025 and OCR of the Dark Side decks before tier 1
is complete; Pinecone Assistant (one-evening spike only, then delete); Linear, Figma; any Python path.
