# A five-minute demonstration

## 0:00–0:40 — The problem

“I wanted to understand how model access, evaluation and tools fit together.
This project compares models on a small set of tasks with visible grading rules.”

Name whether your data is live, fictional fixtures, or both. If you have only
run the offline sample, state that no real model comparison has been completed.

## 0:40–1:30 — Follow a request

Show one prompt. Point out the model ID, API call and returned answer. Explain
the application, router, provider and model in plain language.

## 1:30–2:30 — Read an answer before its score

Show a successful task and a failure. Explain the grader, including an exact
format requirement. Show how failed requests and missing usage are reported.

## 2:30–3:30 — Inspect a calculator action

Show the requested expression, the local calculator result and the final
answer. Compare the same task with no tool. Explain why an available tool may
not be used, and why tool calls can increase time and token usage.
