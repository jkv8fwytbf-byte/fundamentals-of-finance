# Side projects

Three small projects made in September 2026 while the valuation plan was paused. None of them is the valuation system itself. They live here so that everything you made this month sits in one repository.

## Words used in the table

- Git is the tool that records every saved version of a folder. A repository is a folder that git tracks, together with its history.
- A commit is one saved version with a short message. A branch is a named line of commits that can later be joined into `main`.
- To merge is to join one branch into another. On this repository that only happens through a pull request, a request on GitHub to merge, reviewed first.
- A clone is a full copy of a repository, history included. A remote is the copy of a repository kept on a server such as GitHub.
- A `.env` file is a small settings file that often contains keys and passwords. It is never committed; `.env.example` is the same file with the values blanked out.
- `~` means your home folder, `/Users/siddharth`.
- git subtree is a git command that copies another repository's files and commits into a folder of this one.
- Next.js is a toolkit for making websites. FastAPI is a Python toolkit for web services. PostgreSQL with pgvector is a database that can also search text by meaning.
