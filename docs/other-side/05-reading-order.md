# The Other Side, Chapter 5: Reading Order

This chapter is the reading list for the critics' side, arranged for a beginner. It has 17 items. Every item is free unless the table says otherwise. The lengths are the research report's estimates for a careful first pass.

Think of it as a syllabus for one course. You would not read a textbook's chapters in the order the author wrote them. You would read the easy, concrete ones first and the hard, abstract ones last. The order at the end of this chapter does that.

## Two words before the list

A "deck" is a set of presentation slides, usually a PDF. Damodaran teaches from decks, so his shortest free material is in this form.

"SSRN" is the Social Science Research Network, a free archive of academic papers. Each paper has a number. To open one, put the number at the end of this address: https://papers.ssrn.com/sol3/papers.cfm?abstract_id= followed by the number. That address pattern appears in Damodaran's own posts.

A "Monte Carlo" run is a simulation that draws each uncertain input from a range many times and reports the spread of resulting values; item 13 is about how those input ranges are chosen.

## How to read these as a beginner

- Read with the model open. Items 4, 5 and 6 each link to a spreadsheet. Change one input and watch the value move.
- Keep a two-column note for each item: what the critic claims, and what Damodaran conceded. Chapter 4's table is the template.
- Skip the equations on the first pass of items 11, 13 and 14. Read the tables and the conclusions. Return to the equations after your statistics coursework starts.
- When a post gives a value and a price, write both down with the date. Later, look up the split-adjusted price (the old price rescaled for any stock splits since, so that it is comparable with today's per-share price). That habit is the whole scoreboard idea from Chapter 6.
