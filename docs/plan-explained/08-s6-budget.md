# Section 6: Budget at $200 per month

**In short.** A budget is a list of what each tool will cost per month, with a ceiling you will not cross. The plan sets that ceiling at $200 per month (plan section 6). Think of it as a row of small jars, most of them empty today, with one jar you only fill later. The table restates the plan's table with the same figures (plan section 6). "Later" means a paid tier you will only switch on if you need it.

| Line | Now (plan section 6) | Note (plan section 6) |
|---|---|---|
| Cursor Pro | $20 per month, already paid | The code editor with an AI helper inside. Stays on Cursor's own models; no BYOK, meaning no "bring your own key". |
| OpenRouter, runtime | $30 to 70 per month | One door to many AI models. "Runtime" means the models that write memos and answers while the system runs. Spend limit $75. |
| EODHD Fundamentals | $60 per month, only from M4 | Company financial data for India. I will test indianapi.in first; it may save about $50. |
| Hex | $0 now, $36 later | The dashboard tool. Community is free; Professional only for a published app with a daily refresh. |
| GitHub CI | $0 to 25 | The robot that tests code on GitHub. 2,000 free minutes, then $0.006 per minute, capped at $25. |
| Neon | $0 now, about $10 to 20 later | The database, the one place the numbers live. Free until 0.5 GB. |
| Pinecone | $0 now, $20 later | The searchable index of Damodaran's writing. Builder tier only if you re-index often. |
| Voyage, Langfuse Hobby, Cloudflare R2 | $0 | Text embeddings, a log of every model call, and file storage. Free at this scale. |
| Mistral OCR | about $10, one-off | OCR reads text out of images: the three image-only decks and any scanned packet. |
| Optional: Kite Connect, INDstocks API, Parallel | 500 rupees, free, about $18 | India prices and news search. INDstocks API is free with an INDmoney account. |
| Total | about $120 to 200 per month | Ceiling $200. |

Hex, GitHub CI, Neon, Pinecone, Voyage, Langfuse and Cloudflare R2 all start at $0 (plan section 6). EODHD is the one line that only starts at M4, the India phase, at $60 per month (plan section 6). The total is about $120 to 200 per month, under a ceiling of $200 (plan section 6). Bloomberg Digital, your news and market reading subscription, is your own cost and sits outside this budget (plan section 6).

> **What it means for you:** Most of the stack will be free while I build it; the only new money before M4 is OpenRouter, at $30 to 70 per month with a $75 spend limit (plan section 6).
