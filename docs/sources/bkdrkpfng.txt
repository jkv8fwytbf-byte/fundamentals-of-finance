## 2. COMPUTATION CHAIN — `Valuation output` (sheet2), exact formulas

Grid: col **B** = Base year, **C…L** = years 1…10, **M** = Terminal year, **N** = aggregates. Rows below are the real row numbers.

### 2.1 Base-year restatement (row 5, 39)
```
EBIT_0  (B5)  = Input!B12
                + (Input!B17="Yes" ? 'Operating lease converter'!F32 : 0)     ' lease op-income add-back
                + (Input!B16="Yes" ? 'R& D converter'!D39 : 0)                ' R&D expense − amortization
Margin_0(B4)  = B5 / B3                    ; B3 = Input!B11 (LTM revenues)
InvCap_0(B39) = Input!B14 + Input!B15 − Input!B18
                + (lease ? 'Operating lease converter'!F33 : 0)               ' debt value of leases
                + (R&D  ? 'R& D converter'!D35 : 0)                           ' value of research asset
ROIC_0  (B40) = B7 / B39
EBIT(1-t)_0 (B7) = IF(B5>0, B5*(1−B6), B5)  ; B6 = Input!B23 (effective tax rate)
```

### 2.2 Revenue growth → revenues (rows 2–3)
```
g1  (C2) = Input!B26
g2..g5   = Input!B28                      (D2 = Input!B28, E2=D2, F2=E2, G2=F2)
g6..g10  (H2..L2) = g5 − (g5 − g_T)/5 * k,  k = 1..5      → g10 = g_T exactly
g_T (M2) = IF(Input!B67="Yes", Input!B68,
            IF(Input!B64="Yes", Input!B65, Input!B34))     ' perpetuity growth = riskfree by default
Rev_t = Rev_{t-1} * (1 + g_t)             ; Rev_T (M3) = Rev_10 * (1+g_T)
```

### 2.3 Operating margin (row 4) — linear convergence
```
m1 (C4) = Input!B27
for t = 2..10:
  m_t = IF( t > Y_conv, m_target,
            m_target − ((m_target − m1)/Y_conv) * (Y_conv − t) )
  where m_target = Input!B29, Y_conv = Input!B30
m_T (M4) = m_10
EBIT_t (row5) = m_t * Rev_t
```

### 2.4 Tax rate (row 6) and NOL (rows 7, 10)
```
t_1..t_5 = Input!B23 (effective)
t_6..t_10 (H6..L6) = t_{prev} + (t_T − t_5)/5            → t_10 = t_T
t_T (M6) = IF(Input!B59="Yes", Input!B23, Input!B24)     ' default: converge to marginal
NOL_0 (B10) = IF(Input!B61="Yes", Input!B62, 0)
NOL_t (C10) = IF(EBIT_t < 0, NOL_{t-1} − EBIT_t,
                 IF(NOL_{t-1} > EBIT_t, NOL_{t-1} − EBIT_t, 0))
EBIT(1-t)_t (row7) = IF(EBIT_t > 0,
                        IF(EBIT_t < NOL_{t-1}, EBIT_t,             ' fully shielded
                           EBIT_t − (EBIT_t − NOL_{t-1}) * t_t),
                        EBIT_t)                                     ' losses untaxed
EBIT(1-t)_T (M7) = EBIT_T * (1 − t_T)      ' NOL ignored in terminal year
```

### 2.5 Reinvestment via sales-to-capital (row 8) — the lag switch
```
s2c_t (row38) = Input!B31 for t = 1..5 ; Input!B32 for t = 6..10
lag = IF(Input!B56="No", 1, Input!B57)          ' values 0,1,2,3

Reinv_t = (Rev_{t+lag} − Rev_{t+lag-1}) / s2c_t        ' default lag=1 → (Rev_{t+1} − Rev_t)/s2c_t
   (Excel writes the four branches explicitly; for t=9,10 with lag=2/3 it degenerates to
    K8: Rev_T * g_T / s2c ; L8: Rev_T * g_T / s2c ; L8(lag=3): K8*(1+g_T))

Reinv_T (M8) = IF(g_T > 0, (g_T / ROC_stable) * EBIT(1-t)_T, 0)    ' reinvestment rate = g/ROC
N8 = SUM(C8:M8)                                                    ' cumulated reinvestment

FCFF_t (row9) = EBIT(1-t)_t − Reinv_t ;  FCFF_T (M9) = M7 − M8
InvCap_t (row39) = InvCap_{t-1} + Reinv_t
ROIC_t   (row40) = EBIT(1-t)_t / InvCap_{t-1}
ROC_stable (M40) = IF(Input!B48="Yes", Input!B49, L12)             ' = year-10 cost of capital
```
**No floor on reinvestment** in the 2026 sheet — it can go negative when revenues shrink.

### 2.6 Cost of capital path (row 12–13)
```
WACC_1..WACC_5 (C12..G12) = Input!B35 = 'Cost of capital worksheet'!B13
WACC_6..WACC_10 (H12..L12) = WACC_{prev} − (WACC_5 − WACC_T)/5      → WACC_10 = WACC_T
WACC_T (M12) = IF(Input!B45="Yes", Input!B46,
                  IF(Input!B64="Yes", Input!B65 + CERP!B1,
                                      Input!B34 + CERP!B1))          ' rf + mature-market ERP
CumDF_1 (C13) = 1/(1+WACC_1) ;  CumDF_t = CumDF_{t-1} * 1/(1+WACC_t)
PV(FCFF)_t (row14) = FCFF_t * CumDF_t
```

### 2.8 Option value (sheet6) — dilution-adjusted Black-Scholes, circular
```
S=Input!B22, K=Input!B39, T=Input!B40, σ=Input!B41, q=0 (local input B8), r=Input!B34
nW=Input!B38, nS=Input!B21
Adjusted S (B17) = (S*nS + V_total_options*nW) / (nS + nW)     ' B17 = (B15*D16 + B28*D15)/(D16+D15)  <-- circular, needs iteration
Variance D18 = σ^2 ; r_adj D20 = r − q
d1 = (ln(S*/K) + (r−q + var/2)*T) / (sqrt(var)*sqrt(T))
d2 = d1 − sqrt(var)*sqrt(T)
Value/option (B28) = e^(−qT)*S*·N(d1) − K·e^(−rT)·N(d2)
Value of all options (B29) = B28 * nW
```
The circular `Adjusted S` is exactly why `iterate="1"` is required. Reimplementation: fixed-point iterate B17 until convergence.

## 5. SIMPLE GINZU vs FULL GINZU vs CORONA

| Dimension | `fcffsimpleginzu` (2026, 17 sheets) | `fcffginzu` (full, 2024 Eli Lilly example, 15 sheets) | `fcffsimpleginzuCorona` (2020-03-27 Boeing, 15 sheets) |
|---|---|---|---|
| Growth driver | **Revenue growth is the primitive**; margin & sales-to-capital derive EBIT and reinvestment | **Operating income growth from fundamentals**: `g = ROC × Reinvestment Rate`, or direct input. Explicit CapEx, Depreciation, ΔWorking Capital lines | same as simple ginzu |
| Reinvestment | `ΔRevenue / sales-to-capital`, two s2c bands (yrs 1–5 `B31`, yrs 6–10 `B32`), lag switch 0–3 (default 1) | CapEx − Depreciation + ΔNon-cash WC; WC as % of revenues input; stable-growth reinvestment from ROC or CapEx/Depreciation ratio | **single** s2c ratio, **no lag** (contemporaneous), and **floored at zero in year 1**: `C8 = IF(C3>B3,(C3−B3)/Input!B28,0)`; `D8 = (D3−C3)/D38` |
| Horizon | fixed 10 years + terminal | **user-set high-growth length** (`Length of high growth period = 10`), optional gradual adjustment in the second half | fixed 10 |
| Cost of capital | full embedded `Cost of capital worksheet` with 4 approaches, ERP by country/region/operating mix, beta from industry averages, synthetic or actual rating | user types beta, ERP, debt ratio, cost of debt **separately for high-growth and stable** periods; separate `Ratings estimator` | same 4-approach COC worksheet, but industry sheets are only `Industry Average Beta (US)/(Global)` |
| Tax | effective → marginal, linear over years 6–10 | separate effective and stable tax rates, user-set | same as simple (in the Boeing example effective = marginal = 25%, so flat) |
| Distress | probability of failure + proceeds tied to Book or Value | none | same as simple |
| NOL | yes (rows 7/10) | via `Earnings Normalizer` instead | yes |
| Options | dilution-adjusted BS, circular | yes, plus "use current price or estimated value" toggle | yes |
| Non-traded firms | not supported | supported: "Is your stock currently traded? No" → book-value or user-specified debt ratio | not supported |
| Earnings normalizer | none (negative EBIT handled via NOL + tax logic) | dedicated `Earnings Normalizer` sheet; sheet warns to use `highgrowth.xls` if EBIT negative | none |
| Unique sheets | `Valuation as picture`, `Failure Rate worksheet`, `Input Stat Distributioons`, `Diagnostics`, full `Industry Averages` × 2 | `Read me first`, `Earnings Normalizer`, `Input Summary`, `Ratings estimator` | `Summary Sheet` (a flat 4-block year-by-year table: revenue/margin/tax; reinvestment/ROC; COC components; discounting), no `Valuation as picture`, no `Failure Rate`, no `Input Stat Distributioons` |
| Stable cost of capital default | `rf + mature-market ERP` (4.58% + 4.23% = 8.81%) | user types stable beta/ERP/debt ratio/cost of debt | same formula; Boeing: 0.02 + 0.052 = 6.72% |
| Data vintage | Jan 1 2026, rf 4.58%, mature ERP 4.23% | May 2024, rf 4.50%, ERP 4.92% | Mar 27 2020, rf **0.85%**, mature ERP ~5.2% |

Net: **Corona ≡ the March-2020 snapshot of simple ginzu** (same architecture, older/simpler: one s2c, no lag, no failure-rate or distribution sheets, Summary Sheet instead of the picture/diagnostics pair). **Full ginzu is a different model family** — fundamentals-driven growth with explicit capex/depreciation/working-capital, phase-specific risk parameters, and support for private/non-traded firms. For a code re-implementation, target **simple ginzu**; full ginzu only if you need fundamentals-based growth or private companies.

## 7. RE-IMPLEMENTATION NOTES

1. **Iteration is mandatory.** `Option value`!B17 (dilution-adjusted S) depends on total option value which depends on B17. Excel is set to `iterate="1"`. In code: fixed-point loop (or just note that with `Input!B37="No"` the whole option branch is dead and B30 = 0).
2. **Two lookup styles.** Industry/country lookups use `VLOOKUP(..., TRUE)`-style **approximate** match by default (no 4th arg) in most places — for exactly-matching text keys this behaves as exact only if the table is sorted ascending; the industry tables are alphabetical, so it works. `Input Stat Distributioons` lookups use `FALSE` (exact). Rating tables use genuine banded approximate match on a numeric coverage ratio.
3. **`B67` / `B72` hard-code `4.58%`** as the US$ riskfree of the Jan-2026 vintage. Any re-implementation must expose that as `RF_DATASET_VINTAGE`, not a literal.
4. **Row-offset trap in the markdown mirror.** Empty self-closing `<c/>` cells shift values one column left in naive parsers — e.g. FCFF year-1 lives in `C9`, not `B9`. Parse the xlsx, not the MD, for cell addressing.
5. **Defaults that are formulas** (`B27={I26}`, `B28={B26}`, `B29={B27}`, `B31={K27}`, `B32={B31}`, `B46={B35}`, `B62={474.8+256.6}`) must become *initialisers* in code, not permanent bindings — the user is meant to overwrite them.
6. **Unit invariance.** The only per-share quantity is `B22` (price) and `B21` (share count). Everything else is in the same currency unit; the sheet warns explicitly about mixing millions with a raw share count.
