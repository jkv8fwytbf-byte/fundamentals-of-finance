# Decisions log

This folder is the decisions log from rule 6 of `docs/guide/00-how-to-learn-with-an-ai-tool.md`.

One file per decision, named `NNN-title.md`, where `NNN` is a three-digit number counting up from `001`.

Each note is about ten lines and is written by a human. In the rule's words, each note says "what was decided, what was rejected, and why".

The rule calls the log "the only artifact that proves you made the call". It is also the context you hand an AI tool next month, so it stops re-opening settled choices.

An AI tool may draft a note when you ask, but you read every line and change what is wrong before it is committed. A commit is one saved snapshot in git, the program that keeps the folder's history.

Notes so far: `001-one-public-repo-for-everything.md` (2026-09-26, draft, waiting for Siddharth's approval in issue #20).
