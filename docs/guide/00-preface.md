# How to read this document

This is document B of four. Document A ("Read This First") describes the system in plain words.
This guide teaches the tools the system uses, one chapter per tool, so that when a contractor
does its job you understand what it did and can check it.

Each chapter has the same shape: what the tool is (with an analogy), why this tool and not
another, how it is used in this project, where to learn it for free with hours, a ten-minute
exercise, and a "done when" line so you know when to stop.

You do not need to read it front to back. Chapter 0 (how to learn with an AI tool) and chapter 2
(Cursor) come first because you will touch them every day. After that, follow the schedule in
chapter 16: it names the chapters to read each week, alongside the Damodaran sessions in chapter
15. Chapter 17 is the glossary; keep it open in a second window.

Nothing in this guide asks you to open an account or install anything today. Every account you
will eventually need is listed in document A, section 10, and the schedule tells you the week to
open each one. Nothing after M0 starts until you say go.
